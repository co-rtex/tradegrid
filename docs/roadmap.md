# TradeGrid Fall 2026 Roadmap

This roadmap is organized around roughly seven workshop meetings.

## Meeting 1 — Launch + Git/GitHub
- Introduce TradeGrid
- Explain the product and architecture
- Complete first pull request
- Select areas of interest
- Claim Sprint 1 issues

## Meeting 2 — Orders + Matching
- Order domain model
- Limit orders
- Price-time priority
- Matching-engine tests

## Meeting 3 — API + Database + Risk
- REST endpoints
- PostgreSQL model
- Validation and basic risk controls
- Integration work

## Meeting 4 — Frontend + Real-Time
- Trading interface
- Backend integration
- WebSockets
- Live order-book updates

## Meeting 5 — Portfolio + P&L
- Cash and positions
- Cost basis
- Realized/unrealized P&L
- Portfolio UI

## Meeting 6 — Integration + Reliability
- End-to-end testing
- Error handling
- Performance
- Observability / stretch work if MVP is stable

## Meeting 7 — Showcase
- Live multi-user trading demo
- Architecture walkthrough
- Contributor recognition
- Future roadmap

## Definition of Semester Success

Multiple users can receive simulated cash, submit limit orders, match against one another, observe executions, and see portfolio/market state update through one cohesive application.
