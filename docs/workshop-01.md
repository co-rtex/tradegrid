# Workshop 01 — TradeGrid Launch

## Objectives

By the end of the workshop, every participant should:

- Understand what TradeGrid is
- Understand the semester MVP
- Join the project communication channels
- Understand Issue -> Branch -> PR -> Review -> Merge
- Open a first pull request
- Choose an area of interest
- Claim one Sprint 1 issue

## Recommended Agenda — 75 Minutes

### 0:00–0:05 — Welcome
Introduce TradeGrid as the semester technology project.

### 0:05–0:12 — Product Vision
Show dashboard, portfolio, orders, and markets mockups.

### 0:12–0:18 — What Happens Behind a Trade?
Walk through order -> validation -> risk -> matching -> execution -> portfolio -> live update.

### 0:18–0:23 — Who Can Contribute?
Explain starter, beginner, intermediate, and advanced work.

### 0:23–0:28 — Semester Workflow
Explain biweekly sprint boundaries and development between meetings.

### 0:28–0:38 — Git/GitHub Basics
Explain repository, issue, branch, commit, PR, review, merge.

### 0:38–0:58 — First Pull Request
Everyone creates a contributor profile on their own branch and opens a PR.

### 0:58–1:06 — Choose Interest Areas
Frontend, backend, matching/systems, database, quant/analytics, testing/infrastructure.

### 1:06–1:13 — Claim First Real Issue
One active issue per person initially.

### 1:13–1:15 — Close
Before Meeting 2: finish issue, open PR, ask for help when blocked, review at least one teammate PR.
